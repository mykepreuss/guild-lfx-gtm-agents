# Guild Marketing OS Company Context Builder

Guild-native TypeScript LLM agent package for `guild-marketing-os-company-context-builder`.

This agent turns raw company or project context into approved Context Hub drafts, entity facts, proof points, AEO readiness gaps, a Workspace Context update, approval checkpoints, and next-agent routing.

V1 is review-only: it does not publish, schedule, install, spend, sync, or modify live systems.

## Local Checks

From the repository root:

```sh
npm run verify
```

Run `guild agent test` from this package directory when Guild validation is needed. Do not save, publish, install, configure credentials, or create triggers without separate approval.
