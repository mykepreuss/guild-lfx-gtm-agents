# Guild Marketing OS Campaigns And Paid Media

Guild package: `guild-marketing-os-campaigns-paid-media`
Package owner: `michaelpreuss`

## Purpose

Builds campaign briefs, paid-media plans, audience-message matrices, creative test plans, landing-page recommendations, and performance loops.

## Guild Usage

Use after approved messaging, audience segments, channel scope, and proof policy are available. Provide the offer, destination page, budget, target KPI, geography, consent limits, creative assets, and performance data when asking for optimization.

## Operating Boundary

Review-only. This agent does not change spend, launch ads, activate audiences, publish landing pages, or claim performance results without approved data.

## Test

From this package directory:

```sh
guild agent test --workspace michaelpreuss/guild-marketing-os --events none --mode json
```
