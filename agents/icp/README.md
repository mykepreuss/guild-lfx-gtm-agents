# Guild Marketing OS ICP

Guild package: `guild-marketing-os-icp`
Package owner: `michaelpreuss`

## Purpose

Turns approved company context and market evidence into personas, pains, objections, motivations, triggers, fit criteria, disqualifiers, and audience answer priorities.

## Guild Usage

Use after workspace context and, when available, a Market Signal Brief exist. Provide good-fit and poor-fit customer examples, buyer/user roles, adoption triggers, decision criteria, business goals, and evidence limits.

## Operating Boundary

Review-only. This agent does not create CRM records, activate lists, or treat unsupported personas as approved facts.

## Test

From this package directory:

```sh
guild agent test --workspace michaelpreuss/guild-marketing-os --events none --mode json
```
