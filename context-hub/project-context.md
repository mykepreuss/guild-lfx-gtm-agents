## Operating Model

The Marketing OS is a cockpit for project leaders:

- Dials: dashboard status, alerts, tasks in process, campaign performance.
- Controls: launch agents, review work, approve next steps, route execution.

Every agent follows the same loop:

1. Project leader initiates.
2. Agent drafts.
3. Project leader reviews and approves.
4. Agent routes work, prepares execution, or updates status.
5. Dashboard reflects the state.
